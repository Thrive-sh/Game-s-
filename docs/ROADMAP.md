# Roadmap EcoBox

Fase pengembangan untuk solo dev, HP Android 4GB/128GB, modal Rp0.

## Fase 0 — Prototipe Web (SELESAI)
- `index.html` satu file, HTML5 Canvas
- Grid dunia, ekosistem dasar, bencana, tool Tuhan
- Deploy gratis: GitHub Pages / Netlify Drop / itch.io

## Fase 1 — Sistem Intian (MVP)
- Musim & cuaca (hujan, salju, efek ke tumbuh)
- Penyakit / wabah pada makhluk
- Save/load dunia ke localStorage (multi-slot)
- Rumah sederhana / struktur dasar
- Panel statistik populasi + grafik

## Fase 2 — Konten & Aset Gratis
- Spesies tambahan (ayam, naga, unikorn, iblis)
- Trait acak (kuat, cepat, rakus, sosial)
- Bencana tambahan (gempa, tornado, banjir, petir)
- SFX & musik dari freesound.org / Kenney.nl (cek lisensi)
- Ikon tool & panel

## Fase 3 — Port ke Godot 4 (Export APK)
- Pindah logika dari web ke Godot 4 (GDScript)
- Struktur `godot/` cerminkan `src/`
- Export APK Android native, ukuran kecil untuk HP 4GB
- Kontrol sentuh native, zoom/pin kamera

## Fase 4 — Rilis
- itch.io (gratis, tanpa biaya)
- Google Play Store setelah kumpulkan $25 biaya pendaftaran sekali seumur hidup
